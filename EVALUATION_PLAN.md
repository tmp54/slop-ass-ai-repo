# Evaluation Plan

## Problem Grounding

1. Who specifically has the collaboration problem you are addressing? 

Programmers that need work handoff, which exist in every long term project. 
2. What do they currently do instead of your tool?

Find clues in Github, read the docs that is long, and ask question to sender using chat apps.  
3. What would be observably different about their collaboration if your tool worked? 

They can use a shorter time to complete the handoff without the loss of handoff quality. 

## Evaluation Plan Draft

- Success definition — User giving us positive feed back
- Target users — Programmer that need to handoff some code 
- Method — Ask someone to try our system. Asking their feedback by using google form.  
- Minimum evidence threshold — At least two person give positive feedback.
